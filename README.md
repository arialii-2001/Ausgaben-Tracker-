# Ausgaben-Tracker (Expense Tracker)

Ein einfaches Python-Projekt zur Erfassung und Analyse persönlicher Ausgaben.

## Zielsetzung
Das Projekt dient dazu, grundlegende Programmierkonzepte zu üben und zu zeigen, 
wie technische Werkzeuge zur Unterstützung wirtschaftlicher Entscheidungen eingesetzt werden können.

## Funktionen
- Erfassung von Ausgaben (Datum, Kategorie, Beschreibung, Betrag)
- Speicherung in einer CSV-Datei
- Zusammenfassung der Ausgaben nach Kategorien
- Einfache Fehlerbehandlung bei Benutzereingaben

## Technologien
- Python 3
- Standardbibliothek (csv, datetime, os)
- Keine externen Abhängigkeiten
